## How to run

<!-- Write the exact steps someone needs to run your project from scratch.
     Assume they have Node.js, PostgreSQL, and VS Code, and nothing else.
     Include: creating the database, running schema.sql, writing the .env file,
     starting the backend, and opening the frontend. -->

**Backend**


1. تثبيت Node.js وPostgreSQL وVS Code.
2. إنشاء Database في PostgreSQL للمشروع.
3.  فتح قاعدة البيانات في pgAdmin.
4. تشغيل ملف schema.sql لإنشاء جدول المصاريف.
5. إنشاء ملف .env داخل مجلد الـBackend وكتابة بيانات الاتصال بقاعدة البيانات.
6. فتح Terminal داخل مجلد الـBackend.
7. تشغيل npm install لتثبيت الـpackages.


8.من هنا يبداءالتشغيل الفعلي اني افتح التيرمنال من ملف الباك اند  ثم
9. تشغيل السيرفر باستخدام:
node server.js
المفروض بعدها الـBackend يشتغل على localhost:3000.

**Frontend**


1. فتح مجلد المشروع في VS Code.
2. فتح ملف index.html.
3. تشغيله باستخدام Live Server.
4. فتح التطبيق في المتصفح.
